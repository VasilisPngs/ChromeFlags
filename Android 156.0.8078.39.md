# Android 156.0.8078.39

**Enable Instant API on Android**

Enables Instant API for Android devices.

`chrome://flags/#ntp-enable-instant-api-android`

---

**NTP Realbox Cycling Placeholders**

Enables cycling placeholders within the Realbox 'Next' experience.

`chrome://flags/#ntp-realbox-cycling-placeholders`

---

**NTP Searchbox (Realbox) Voice Search Coherence**

Enables the voice search coherence experiment (new recording animation, new metrics, added stop/submit button) for the New Tab Page searchbox, with option for live transcription.

`chrome://flags/#ntp-searchbox-voice-search-coherence`

---

**Omnibox Fusebox Popup Variations**

Enables popup variations (with the accordion menu) for the mobile Fusebox popup.

`chrome://flags/#omnibox-fusebox-popup-variations`
