# Android 153.0.8010.18

**Account Picker Dialog**

Enables the account picker dialog on large form factors.

`chrome://flags/#account-picker-dialog`

---

**Always show install or create shortcut disambiguation dialog**

Always show the PWA universal install bottom sheet disambiguation dialog instead of auto-redirecting to the install or shortcut creation dialog.

`chrome://flags/#always-show-install-disambiguation-dialog`

---

**Android Desktop Bookmark Layout**

Enables the desktop-styled bookmark layout on Android Desktop devices.

`chrome://flags/#android-desktop-bookmark-layout`

---

**Android Desktop History Layout**

Enables the new history manager layout for Android desktop.

`chrome://flags/#android-desktop-history-layout`

---

**Android Fre Layout Update**

Enables updated FRE layout on Android.

`chrome://flags/#android-fre-layout-update`

---

**Toolbar capture on desktop**

Disables toolbar bitmap capture when scrolling is disabled for top controls on Android desktop.

`chrome://flags/#android-no-capture-when-scrolling-disabled-on-desktop`

---

**Android YUV Overlay Even Alignment**

Enforces 2-pixel even boundary alignment for YUV hardware video overlays in SurfaceControl to prevent odd-coordinate display scaling rejections.

`chrome://flags/#android-yuv-overlay-even-alignment`

---

**Autofill AI always show Private AI notice**

Forces the Autofill AI Private AI notice suggestion to be shown for testing, skipping cool-off timers and impression count checks.

`chrome://flags/#autofill-ai-always-show-private-ai-notice`

---

**Autofill and passwords remove sign-in promo**

`chrome://flags/#autofill-and-passwords-remove-sign-in-promo`

**Autofill Keyboard Accessory Hover Preview on Android**

`chrome://flags/#autofill-android-keyboard-accessory-hover-preview`

---

**Enable Autofill settings enterprise policy**

When enabled, the Autofill settings enterprise policy takes effect, and forms ai settings are decoupled from Autofill profile settings.

`chrome://flags/#autofill-enable-autofill-settings-enterprise-policy`

---

**Enable Expand IBAN Regex Pattern**

When enabled, IBAN regex pattern matching is expanded to support more formats.

`chrome://flags/#autofill-enable-expand-iban-regex-pattern`

---

**Enable 'Scan card' option when no cards saved**

When enabled, the 'Scan new card' option will be offered even if the user does not have any credit cards saved in Autofill.

`chrome://flags/#autofill-enable-scan-card-option-when-no-cards-saved`

**Enable Wallet Reminder Notice**
