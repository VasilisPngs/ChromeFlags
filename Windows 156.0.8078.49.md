# Windows 156.0.8078.49

**Enable Autofill Cardholder Name Fix Flow**

When enabled, prompts users to confirm their cardholder name when checking out with a server card that is missing a name, if a name was found.

`chrome://flags/#autofill-enable-cardholder-name-fix-flow`

---

**Enable Omnibox Autofill chip for Google Pay buttons**

When enabled, a Google Pay omnibox chip will appear when a Google Pay button is detected on the page, and clicking the chip will simulate clicking the Google Pay button.

`chrome://flags/#autofill-enable-omnibox-gpay-button`

---

**Filter Browsing History By Device**

Enables browser history filtering by device.

`chrome://flags/#browsing-history-filter-by-device`

---

**Composebox Outside Click (Realbox)**

Clicking outside the Realbox Composebox closes the suggestions dropdown and restores page interaction while keeping the Composebox open.

`chrome://flags/#composebox-realbox-outside-click`

---

**Contextual Tasks Context Multi-Turn Tab Relevance**

Enables multi-turn tab relevance model for contextual tasks.

`chrome://flags/#contextual-tasks-context-multi-turn-tab-relevance`

---

**Contextual Tasks Ephemeral Button Context Menu**

Enables a context menu on the ephemeral contextual tasks toolbar button to remove it from the toolbar.

`chrome://flags/#contextual-tasks-ephemeral-button-context-menu`

---

**Contextual Tasks Updated Entry Points**

Enables updated entry points for contextual tasks.

`chrome://flags/#contextual-tasks-updated-entry-points`

---

**Copy-Text Journeys**

Enables offering to reopen a search answer in the Contextual Tasks side panel.

`chrome://flags/#copy-text-journeys`

---

**Default Browser Sticky Modal**

Enables the sticky modal dialog for the default browser prompt. Requires #default-browser-prompt-surfaces to be set to a modal dialog variation.

`chrome://flags/#default-browser-sticky-modal`

---

**Enterprise Signin Dialogs Refresh**

Enables the visually refreshed enterprise signin dialogs (enterprise profile welcome/creation, OIDC and the device signals disclaimer). It is no-op if `first-run-desktop-refresh` is disabled.

`chrome://flags/#enterprise-signin-dialogs-refresh`

---

**Feedback Disabled Dialog**

Enables the dialog shown when user feedback is disabled.

`chrome://flags/#feedback-disabled-dialog`

---

**Focus Selection**

Allows focusing a selection of ungrouped tabs in the tabstrip.

`chrome://flags/#focus-selection`

---

**Glic experimental triggering**

Enables GLIC experimental triggering

`chrome://flags/#glic-experimental-triggering`

---

**Glic experimental triggering script tool execution**

Enables direct ScriptTool action execution for Glic experimental triggering tasks.

`chrome://flags/#glic-experimental-triggering-script-tools`

---

**NTP Shortcuts Reorder**

Enables shortcut reordering entrypoint on the New Tab Page.

`chrome://flags/#ntp-shortcuts-reorder`

---

**PDF Accessibility Heuristic Enhancements**

Enables heuristic enhancements for PDF accessibility.

`chrome://flags/#pdf-accessibility-heuristic-enhancements`

---

**Search Settings With More Prepopulated Engines**

Populates the Search settings page with all prepopulated engines.

`chrome://flags/#search-settings-with-more-engines`

---

**Send Tab to Self No Target Device QR Code**

Shows a QR code to download and sign in to Chrome on mobile when no target devices are found in Send Tab to Self.

`chrome://flags/#send-tab-to-self-no-target-device-qr-code`

---

**Skills App Menu**

Shows the Skills sub-menu item in the Chrome app menu.

`chrome://flags/#skills-app-menu`

---

**Temporarily unexpire M155 flags.**

Temporarily unexpire flags that expired as of M155. These flags will be removed soon.

`chrome://flags/#temporary-unexpire-flags-m155`
