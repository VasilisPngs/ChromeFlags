# Windows 155.0.8059.12

**App Menu Glow Up**

Enables the App Menu Glow Up feature.

`chrome://flags/#app-menu-glow-up`

---

**Enable Wallet Direct Offers Notification Bubble**

When enabled, an offer notification bubble will be shown for wallet direct offers if any are available for the current merchant page.

`chrome://flags/#autofill-enable-wallet-direct-offers-notification-bubble`

---

**Enable Wallet Disclosure Notice for public passes**

When enabled, shows the Wallet Disclosure Notice at the end of the save prompt for public passes.

`chrome://flags/#autofill-enable-wallet-disclosure-notice-public-pass`

---

**Browser Actuator Internals**

Enables the chrome://browser-actuator-internals diagnostic dashboard.

`chrome://flags/#browser-actuator-internals`

---

**Browsing History Improved Hostname Suffix Matching**

Improves hostname suffix matching for browsing history, so that example.com matches example.com as well as subdomains like www.example.com.

`chrome://flags/#browsing-history-improved-hostname-suffix-matching`

---

**Composebox Persistent AIM Button (Omnibox)**

Persists the AIM button in the Omnibox Composebox.

`chrome://flags/#composebox-persistent-aim-button-omnibox`

---

**Composebox Persistent AIM Button (Realbox)**

Persists the AIM button in the Realbox Composebox.

`chrome://flags/#composebox-persistent-aim-button-realbox`

---

**Composebox Persistent AIM Button With X**

Shows an X icon on the persistent AIM button. Only effective if the persistent AIM button is also enabled for the surface.

`chrome://flags/#composebox-persistent-aim-button-with-x`

---

**Contextual Tasks Clobber Active Tab**

Enables clicking links in the contextual tasks side panel to clobber the active tab instead of opening in a new tab.

`chrome://flags/#contextual-tasks-clobber-active-tab`

---

**Dark Mode Surface Tokens**

When enabled, updates the surface tokens for dark mode.

`chrome://flags/#dark-mode-surface-tokens`

---

**Network backend linking in DevTools**

Enables backend linking for network requests in DevTools.

`chrome://flags/#devtools-network-backend-linking`

---

**Enable Account Preview Preferred Account Followup**

Controls whether followup features for preferred account preview (promos, and updated strings) are enabled.

`chrome://flags/#enable-account-preview-preferred-account-followup`

---

**Enable Desktop QR code detection**

When enabled, QR code detection for facilitated payments will be supported on Desktop.

`chrome://flags/#enable-desktop-qr-code-detection`

---

**Device Bound Session Credentials (Standard) - Audience Claim**

Enables including the 'aud' (audience) claim in Device Bound Session Credentials registration and refresh JWT payloads.

`chrome://flags/#enable-standard-device-bound-session-credentials-audience`

---

**Translate PDF documents**

Enables PDF translation in Chrome.

`chrome://flags/#enable-translate-pdf`

---

**Treat localhost URLs as sensitive**

When enabled, treats localhost URLs as sensitive origins for the actor.

`chrome://flags/#glic-actor-localhost-is-sensitive`

---

**Glic Experimental Triggering OS Notification**

Enables OS-level system notifications for Glic experimental triggering task starts when no browser window is active.

`chrome://flags/#glic-experimental-triggering-os-notification`

---

**Glic No Webview**

Runs the Glic client in a PrivilegedWebContents instead of a webview.

`chrome://flags/#glic-no-webview`
