# iOS-iPadOS 153.0.8010.24

**AimCobrowse**

Enables the AimCobrowse feature.

`chrome://flags/#aim-cobrowse`

---

**Autofill AI always show Private AI notice**

Forces the Autofill AI Private AI notice suggestion to be shown for testing.

`chrome://flags/#autofill-ai-always-show-private-ai-notice`

---

**Enable Wallet Reminder Notice**

When enabled, shows the Wallet Reminder Notice after payment form submission if higher-priority Autofill features (such as mandatory re-auth, VCN, or card save) do not take precedence.

`chrome://flags/#autofill-enable-wallet-reminder-notice`

---

**Composebox AIM Rich APC Extraction**

Enables rich APC (v2) extraction when attaching tabs in Composebox (AIM).

`chrome://flags/#composebox-aim-rich-apc-extraction`

---

**Enable Composebox connected apps setting**

Enables the composebox connected apps setting, the setting is used to load the web page where the user can the connect their Google apps to the search services

`chrome://flags/#composebox-connected-apps-setting`

---

**Enable Dynamic Route Fetching**

Enables fetching proxy configurations and routing rules dynamically from Provisioning Domains.

`chrome://flags/#enable-dynamic-route-fetching`

---

**FullscreenEasedTransitions**

Enables eased, animated threshold transitions into and out of fullscreen.

`chrome://flags/#fullscreen-eased-transitions`

---

**Gemini FRE Experiment**

Enables the experimental Gemini First Run Experience

`chrome://flags/#gemini-fre-experiment`

---

**Gemini Insights Chip Ablation**

When enabled, the generic Gemini suggestion chip is disabled.

`chrome://flags/#gemini-insights-chip-ablation`

---

**Actor autofill**

Enables autofill actions for the actor tools on iOS. Specific fillable types may also need to be enabled.

`chrome://flags/#glic-actor-autofill`

---

**Settings Default Browser Promo V2**

When enabled, shows the Default Browser Promo V2 in Settings.

`chrome://flags/#ios-settings-default-browser-promo-v2`

---

**Lens Bypass Compression for C2PA**

Bypasses image downscaling and compression if a C2PA metadata urn is detected, ensuring provenance is preserved during upload. Works across all surfaces.

`chrome://flags/#lens-bypass-compression-for-c2pa`

---

**New Geolocation Permission Delegate**

Enables the new geolocation permission delegate feature to help users manage location permission updates when sharing their location with the browser.

`chrome://flags/#new-geolocation-permission-delegate`

---

**New Tab Page UI cleanup**

Enables a UI refresh on the New Tab Page with updated padding, fakebox styling, and color improvements. Different variations adjust the spacing between modules.

`chrome://flags/#new-tab-page-ui-cleanup`

---

**NTP MVT in Bottom Sheet**

Places the Most Visited Tiles inside the bottom sheet card for the NTP Redesign.

`chrome://flags/#ntp-mvt-in-bottom-sheet`

---

**Omnibox Paste Flow Default Browser Promo Experiment**

Enables non-modal default browser promo experiment arms for Omnibox navigation.

`chrome://flags/#omnibox-paste-promo-experiment`

**Page Context PDF**

Enables PDF support for Page Context in Gemini.

`chrome://flags/#page-context-pdf`

**Prepopulated Engines Shadow Variants**

Enables shadow variants for prepopulated engines resolution, allowing alternative engines to be resolved in specific regions.

`chrome://flags/#prepopulated-engines-shadow-variants`

**Voice Search Microphone Permissions**

Enables microphone permissions optimizations for voice search.

`chrome://flags/#voice-search-mic-permissions`

**WebFrame Tree Structure**
