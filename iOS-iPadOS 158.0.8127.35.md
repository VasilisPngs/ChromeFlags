# iOS-iPadOS 158.0.8127.35

**Enable the Android Switcher Default Browser Promo in the FRE**

When enabled, signed-in Android switchers will see the Android Switcher Default Browser Promo in the FRE.

`chrome://flags/#android-switcher-default-browser-promo-in-fre`

---

**Enable Autofill OAuth2 token fix**

When enabled, Autofill payments requests fetch OAuth2 tokens from the identity service on each request, instead of keeping local cache in Autofill components.

`chrome://flags/#autofill-enable-oauth2-token-fix`

---

**Enable Account Preview Preferred Account in FRE**

Controls whether preferred account preview is enabled in the First Run Experience (FRE).

`chrome://flags/#enable-account-preview-preferred-account-fre`

---

**Background Continued Processing**

Enables background continued processing task support on iOS 26+.

`chrome://flags/#enable-background-continued-processing`

---

**Grey Image CIFilter**

Uses Core Image CIFilter instead of UIGraphicsImageRenderer for grayscale image rendering.

`chrome://flags/#grey-image-cifilter`

---

**Unified Manual Fallback Sheet**

Enables the unified manual fallback bottom sheet with a single entry point, all Autofill entity categories, and entity detail views on iOS.

`chrome://flags/#ios-unified-manual-fallback-sheet`

---

**Lens Send Drive Tab URLs in Composeboxes**

Enables sending Google Drive / Docs tab URLs as unresolved URLs in composeboxes.

`chrome://flags/#lens-send-drive-tab-urls-in-composeboxes`

---

**Lens Use Separate Request ID for Viewport Images**

Enables using separate request IDs for page contents vs page viewport uploads.

`chrome://flags/#lens-use-separate-request-id-for-viewport-images`

---

**Magic Stack NTP Customization tip**

Enables the NTP Customization tip on iOS with Non-Actionable or Actionable variations

`chrome://flags/#magic-stack-ntp-customization-tip-ios`

---

**Magic Stack NTP Theme tip**

Enables the NTP Theme tip on iOS with Non-Actionable or Actionable variations

`chrome://flags/#magic-stack-ntp-theme-tip-ios`

---

**Magic Stack Tips Notification tip**

Enables the Tips Notification tip on iOS with Non-Actionable or Actionable variations

`chrome://flags/#magic-stack-tips-notification-tip-ios`

---

**Migrate to SigninReauthCoordinator**

When enabled, primary account reauthentication flows use SigninReauthCoordinator instead of SigninCoordinator.

`chrome://flags/#migrate-to-signin-reauth-coordinator`

---

**Omnibox Truncate Search URL**

Truncates search URLs for the original query ('oq') and query ('q') parameters across various length limits.

`chrome://flags/#omnibox-truncate-search-url`

---

**Enable password sharing with remote actors**

Enables remote actors to request passwords from the signed in Google account. When requested, the user will be prompted to select a password and authenticate.

`chrome://flags/#remote-actor-credential-sharing`

---

**Use different method for zooming web pages**

When enabled, switches the method used to zoom web pages.

`chrome://flags/#webpage-alternative-text-zoom`

---

**Enable text zoom on iPad**

When enabled, text zoom works on iPad

`chrome://flags/#webpage-text-zoom-ipad`
