# iOS-iPadOS 156.0.8078.54

**AIM Cobrowse Web Selection Search**

When enabled, 'Search with Google' in the web selection menu opens Cobrowse with the selected text.

`chrome://flags/#aim-cobrowse-web-selection-search`

---

**AppBar Assistant Customization**

When enabled, long pressing the AppBar assistant button shows a menu to choose which entry point the button shows.

`chrome://flags/#app-bar-assistant-customization`

---

**Disable App Bar long press**

When enabled, disables long-press context menus on the App Bar buttons.

`chrome://flags/#app-bar-disable-long-press`

---

**App Bar static symbol when hidden**

When enabled, the App Bar tab grid button swaps its symbol without an animated content transition while the App Bar is not visible.

`chrome://flags/#app-bar-static-symbol-when-hidden`

---

**Filter Browsing History By Device**

Enables browser history filtering by device.

`chrome://flags/#browsing-history-filter-by-device`

---

**Browsing History Grouping Improvements**

Enables improvements to grouping of similar browsing history.

`chrome://flags/#browsing-history-similar-visits-grouping`

---

**Client Side Detection Server Model for Scam Detection on iOS**

Enables server model for scam detection on iOS. Requires #client-side-detection-ios to be enabled.

`chrome://flags/#client-side-detection-server-model-for-scam-detection-ios`

---

**Enable Cobrowse on AIM SRP Tap**

Enables Cobrowse to automatically open when a user taps a link on an AIM SRP page.

`chrome://flags/#enable-cobrowse-on-aim-srp-tap`

---

**Gemini Contextual Suggestions Cues UI Mode**

Selects the UI presentation mode for Gemini contextual suggestions cues (Infobar Then Omnibox Chip, Infobar Only, or Omnibox Chip Only).

`chrome://flags/#gemini-contextual-suggestions-cues-ui-mode`

---

**Gemini Host Experiment IDs**

Passes active Chrome iOS Finch GWS variation IDs to the embedded Gemini iOS SDK.

`chrome://flags/#gemini-host-experiment-ids`

**Import and export flags**

Enables importing and exporting flags from chrome://flags.

`chrome://flags/#import-export-flags`

**Light App Bar**

When enabled, the App Bar adapts its appearance to follow the user's preferred light or dark interface style.

`chrome://flags/#light-app-bar`

**LocationBarPerformanceImprovements**

Enables performance improvements for the location bar.

`chrome://flags/#location-bar-performance-improvements`

**New Tab Page Ephemeral Theme**

`chrome://flags/#new-tab-page-ephemeral-theme`

**Page Classification**

Enables the page classification framework and configures classification mode.

`chrome://flags/#page-classification`
