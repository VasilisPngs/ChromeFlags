# iOS-iPadOS 155.0.8059.24

**AimHistoryThreadsManagement**

Enables the AimHistoryThreadsManagement feature.

`chrome://flags/#aim-history-threads-management`

---

**Enable Wallet Disclosure Notice for public passes**

When enabled, shows the Wallet Disclosure Notice at the end of the save prompt for public passes.

`chrome://flags/#autofill-enable-wallet-disclosure-notice-public-pass`

---

**Client Side Detection on iOS**

Enables Client Side Detection (CSD) for phishing on iOS.

`chrome://flags/#client-side-detection-ios`

---

**Default Browser Non-Modal Promo Strings**

When enabled, enables new string variations for the default browser non-modal promo on omnibox paste.

`chrome://flags/#default-browser-non-modal-promo-strings`

---

**Default Browser PiP Text Video**

When enabled, displays a text video in the default browser picture-in-picture instead of the current one.

`chrome://flags/#default-browser-pip-text-video`

---

**Enable Account Preview Preferred Account Followup**

Controls whether followup features for preferred account preview (promos, and updated strings) are enabled.

`chrome://flags/#enable-account-preview-preferred-account-followup`

---

**Enable Lens on iPad**

When enabled, enables Lens Viewfinder entry points on iPad.

`chrome://flags/#enable-lens-on-ipad`

---

**Hide Toolbar**

When enabled, adds a button in the long press omnibox menu that forces the fullscreen mode on iOS.

`chrome://flags/#hide-toolbar`

---

**Contextual Default Browser Promo**

Enables the contextual default browser promo half-sheet.

`chrome://flags/#ios-default-browser-contextual-promo`
